# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha pessoas de todos os níveis de experiência, critique ideias e não
pessoas, e não tolere assédio de qualquer tipo.

Comportamentos inaceitáveis podem ser reportados de forma privada ao mantenedor pelo perfil do
GitHub [@JhonathanCosta-Dev](https://github.com/JhonathanCosta-Dev). Todas as denúncias serão
analisadas com sigilo.
